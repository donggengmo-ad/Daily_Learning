# 本地 SQL 注入实验程序

这是教程配套的故意脆弱程序，仅用于本机学习。它只监听 `127.0.0.1:8765`，数据库位于内存中，重启后自动恢复初始数据。

```bash
python3 local_sqli_lab.py
```

可用路由：

| 路由 | 用途 |
|---|---|
| `/product?id=1` | 数字上下文、联合查询和错误观察 |
| `/search?q=SQL` | `LIKE` 字符串上下文 |
| `/login?username=...&password=...` | 故意脆弱的认证查询 |
| `/blind?id=1` | 只返回 Found/Not found 的布尔盲注 |
| `/time?id=1` | 注册 `lab_sleep()` 的时间差实验 |
| `/safe/product?id=1` | 参数化查询对照 |

程序数据均为虚构内容，登录表故意使用虚构明文口令以便展示错误设计。不要把代码复制到真实服务，也不要把监听地址改成 `0.0.0.0`。
