# vim

[TOC]

## 调用命令
`vim <option> <filename>`
- `-R`: 只读模式
- `-c <command>`: 打开文件后执行命令
- `-u <vimrc>`: 使用指定的 vim 配置文件

## 普通模式
### 模式切换
#### 插入模式
- 光标相邻
  - `i`: 光标前
  - `a`: 光标后
- 行首尾
  - `I`: 行首
  - `A`: 行尾
- 新行
  - `o`: 在当前行下方新开一行
  - `O`: 在当前行上方新开一行
- 替换（临时进入）
  - `r`: 替换光标所在字符
  - `R`: 替换光标所在字符及之后的字符

#### 其他模式
- `v`: 进入可视模式
- `:`: 进入命令模式

### 光标移动
#### 平移
- 行内
  - `h`: 向左移动
  - `l`: 向右移动
- 换行
  - `j`: 向下移动
  - `k`: 向上移动
  
#### 单词
- 上个词
  - `w`: 移动到下一个单词开头
  - `e`: 移动到下一个单词结尾
- 下个词
  - `b`: 移动到上一个单词开头
  - `ge`: 移动到上一个单词结尾

#### 跳转
- 行
  - `0`: 跳转到行首
  - `$`: 跳转到行尾
- 文件
  - `gg`: 跳转到文件开头
  - `G`: 跳转到文件结尾

### 文本操作
- 删除
  - `x`: 删除光标所在字符
  - `dd`: 删除当前行
  - `dw`: 删除当前单词

- 修改
  - `cc`: 修改当前行 
  - `cw`: 修改当前单词 

- 复制粘贴
  - `yy`: 复制当前行
  - `yw`: 复制当前单词
  - `p`: 粘贴到下一行
  - `P`: 粘贴到上一行

### 关键词搜索
- `/<pattern>`: 开始搜索
- `n`: 下一个匹配
- `N`: 上一个匹配

### 操作之操作
- `u`: 撤销上一次操作
- `CTRL + r`: 重做上一次撤销操作
- `.`: 重复上一次操作

### 多次操作
`<number> + <command>`

## 插入模式
### 模式切换
- `ESC`: 回到普通模式

### 编辑
正常文本编辑

## 命令模式
### 模式切换
- `ESC`: 回到普通模式

### 退出
- `q`: 退出
- `q!`: 强制退出（不保存修改）
- `wq`: 保存并退出

### 其他
- `w`: 保存目前修改

## 配置文件
### 寻找
- `vim --version`: 查看配置文件路径
- `<path>/vimrc`: 用户配置文件

### 设置
- `set <option>`: 设置选项
- `set no<option>`: 关闭选项
- `set <option>=<value>`: 设置选项值

### 常用选项
- 显示
  - `number`: 显示行号
  - `relativenumber`: 显示相对行号
  - `cursorline`: 高亮光标所在行
  - `showmode`: 显示当前模式
  - `showcmd`: 显示命令

- 搜索
  - `ignorecase`: 搜索时忽略大小写
  - `hlsearch`: 高亮搜索结果

- 格式
  - `autoindent`: 继承上行缩进
  - `smartindent`: 基本智能缩进
  - `tabstop`: 制表符宽度
