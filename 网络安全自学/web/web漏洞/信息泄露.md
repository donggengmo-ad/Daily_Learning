# 信息泄露
[TOC]

## 简介
系统向未授权方暴露了不该暴露的信息。很多时候单个信息泄露看似无关紧要，但碎片化信息可能拼凑成完整攻击链

## 分类
### 版本泄露
暴露服务器版本号，攻击者从而得知文件路径、已知漏洞等等。

经常暴露在 HTTP 响应头中
```http
Server: Apache/2.4.41
```

### 路径泄露
源码或报错中泄露
```php
include('/var/www/html/config/db.php'):
failed to open stream: 
No such file or directory in /var/www/html/index.php on line 10
```

目录列举泄露，自动列出所访问目录下的所有文件
```http
GET /file HTTP/1.1
```

macOS 下的 `.DS_Store` 泄露目录结构
```
.DS_Store
```

### 源码泄露
#### 备份文件泄露
```gitignore
*.bak
*.old
*.save
*~
backup.zip
www.tar.gz
```

#### Vim 缓存泄露
用 vim 访问原名以恢复
```gitignore
.*.swp
.*.swo
.*.swn
```

#### git 泄露
```gitignore
.git/
```

常用工具 `githacker` 重建整个仓库
```bash
githacker --url target --output-folder result
```

#### svn 泄露
```gitignore
.svn/
```

### 配置泄露
可直接查看秘钥等
```gitignore
.env
config.php
```

### robots.txt
`robots.txt` 用于告诉搜索引擎哪些页面不应该被索引，可能包含隐藏路径。

### phpinfo
`phpinfo.php` 会泄露 PHP 配置信息。
