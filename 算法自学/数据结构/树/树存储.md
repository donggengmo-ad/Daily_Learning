# 一般树存储
一般表示法有
- 双亲表示法
- 孩子表示法
- 孩子兄弟表示法

## 双亲表示法
#### 定义
每个结点存储一个指向其父结点的指针（或索引）
#### 特点
访问父结点方便，访问子结点不方便
#### 结构体定义
```cpp
struct PTNode {
    char data; // 结点数据
    struct PTNode* parent; // 父结点指针
};
```
## 孩子表示法
#### 定义
每个结点存储所有子结点的链表（或数组）
#### 特点
访问父结点不方便，访问子结点方便
#### 结构体定义
顺序存储
```cpp
struct CTNode {
    char data; // 结点数据
    vector<CTNode*> children;// 子结点在数组中的位置
};
```
链式存储
```cpp
struct CTNode {
    char data; // 结点数据
    CTNode* firstChild; // 子节点链表头指针
};
```
## 孩子兄弟表示法
#### 定义
每个结点存储
- 一个指向第一个子结点的指针
- 一个指向下一个兄弟结点的指针
#### 特点
访问父结点不方便，访问子结点和兄弟结点方便
#### 结构体定义
```cpp
struct CSNode {
    char data; // 结点数据
    struct CSNode* firstChild; // 第一个子结点指针
    struct CSNode* nextSibling; // 下一个兄弟结点指针
};
```
## 全tm连上表示法（一般不用）
#### 定义
每个结点存储
- 一个指向父结点的指针
- 一个指向第一个子结点的指针
- 一个指向下一个兄弟结点的指针
#### 特点
访问父结点、子结点和兄弟结点都方便，但存储空间大
#### 结构体定义
```cpp
struct FullNode {
    char data; // 结点数据
    struct FullNode* parent; // 父结点指针
    struct FullNode* firstChild; // 第一个子结点指针
    struct FullNode* nextSibling; // 下一个兄弟结点指针
};
```
