# 左偏树
[toc]
## 介绍
一种可高效合并的堆结构，具有以下性质：
- **堆序性**：任意节点值 $\geq$（或 $\leq$）子节点值。
- **左偏性**：$dist_l \geq dist_r$

## $dist$标记
### 定义
dist表示某个节点到空节点的最短距离
- 空节点 $dist = -1$
- 叶节点 $dist = 0$
- 非叶节点 $dist = min(dist_l, dist_r)+ 1$
### 左偏树性质
根据左偏性（$dist_l \geq dist_r$），可知每个节点的 $dist$ 均来自右子树
- 即 $dist = dist_r + 1$ 

## 存储
不是完全二叉树，不适合顺序存储，但可以使用数组模拟链式存储，维护如下信息：
- $dist$：节点到空节点的最短距离
- $val$：节点值
- $l$：左子节点
- $r$：右子节点
```cpp
struct LeftHeap{
    struct Node{
        int dist = 0, val = 0;
        int l = 0, r = 0;
        Node(int v): val(v) {}
    };
    vector<Node> tr;
    LeftHeap(): {
        tr.emplace_back(0);
        // 空节点 dist 设为 -1
        tr[0].dist = -1;
    }
};
```


## 合并操作
### 步骤
- 检查两个堆的根节点是否为空
- 比较两个堆的根节点，维护堆序性
- 递归合并至右子树
- 回溯维护左偏性
### 代码
```cpp
int merge(int x, int y){
    // 任意一个为空，直接返回另一个
    if(!x || !y) return x | y;
    // 取较小的作为新根（设置为x）
    if(tr[x].val > tr[y].val) 
       swap(x, y);
    // 合并堆到新根右子树
    tr[x].r = merge(tr[x].r, y);
    // 维护左偏性，如果左树dist小于右树，交换左右子树
    if(tr[tr[x].l].dist < tr[tr[x].r].dist) 
        swap(tr[x].l, tr[x].r)
    // 更新新根dist = 新根右子树dist + 1
    tr[x].dist = tr[tr[x].r].dist + 1;
    return x;
}
```

## 其他操作
### 插入
- 把插入元素看成单点堆
- 合并单点堆到主堆
```cpp
int insert(int root, int val){
    // 新建单点堆，叶子节点 dist = 0   
    tr.emplace_back(val);
    return merge(root, tr.size() - 1);
}
```
### 删除
- 合并根节点的左右子树
- 合并后新根代替原有根节点
```cpp
int del(int root){
    return merge(tr[root].l,  tr[root].r);
}
```
### 查询
查询根节点的值
```cpp
int query(int root){
    return tr[root].val;
}
```

## 并查集寻根
通常用一个并查集，记录数组中每个元素属于哪个堆，即记录每个元素的根节点
```cpp
DSU dsu;
LeftHeap heap;
// 合并两个堆
void merge(int x, int y){
    // 找到堆根
    int rx = dsu.find(x);
    int ry = dsu.find(y);
    // 合并堆得到新根
    int root = heap.merge(rx, ry);
    // 更新并查集记录的根节点
    dsu.set_paretn(rx, root);
    dsu.set_parent(ry, root);
}
// 删除堆顶
void pop(int x){
    // 找到堆顶
    int rx = dsu.find(x);
    // 删除堆顶得到新根
    int root = heap.pop(rx);
    // 原根指向新根
    dsu.set_parent(rx, root);
    // 新根指向自己
    dsu.set_parent(root, root);
}
```

## 复杂度
### 时间复杂度
- 合并操作：$O(\log n)$
- 插入操作：$O(\log n)$
- 删除操作：$O(\log n)$
- 查询操作：$O(1)$
- 并查集寻根：$O(1)$
### 空间复杂度
- 存储：$O(n)$
- 并查集：$O(n)$
