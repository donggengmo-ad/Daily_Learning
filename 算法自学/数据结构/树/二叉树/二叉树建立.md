# 二叉树建立
根据不同序列确定方式不同
- 层序：只能确定根节点（第一个节点）
- 先序：只能确定根节点（第一个节点）
- 后序：只能确定根节点（最后一个节点）
- 中序：无法确定，但知道根可划分左右子树

因此通常用 $中序+其他$ 来确定二叉树结构

## 先序+中序
1. 先序第一个节点为根节点
2. 在中序中找到根节点位置，划分左右子树
3. 递归构建左右子树
```cpp
Node* preBuild(
    int pre[], int in[],
    int pl, int pr, 
    int il, int ir
    ) {
    // 递归出口
    if(pl > pr || il > ir) return nullptr;
    // 创建新根节点
    Node* root = new Node(pre[pl]);
    // 在中序中找到根节点位置
    int rootI = il;
    while(in[rootI] != root->val) rootI++;
    // 计算左子树大小
    int lSize = rootI - il;
    // 递归构建左右子树
    root->left = preBuild(
        pre, in,
        // 左子树在前半部分
        pl + 1, pl + lSize,
        il, rootI - 1
    );
    root->right = preBuild(
        pre, in,
        // 右子树在后半部分
        pl + lSize + 1, pr,
        rootI + 1, ir
    );
    return root;
}
```
## 后序+中序
1. 后序最后一个节点为根节点
2. 在中序中找到根节点位置，划分左右子树
3. 递归构建左右子树
```cpp
Node* postBuild(
    int post[], int in[],
    int pl, int pr, 
    int il, int ir
    ) {
    // 递归出口
    if(pl > pr || il > ir) return nullptr;
    // 创建新根节点
    Node* root = new Node(post[pr]);
    // 在中序中找到根节点位置
    int rootI = il;
    while(in[rootI] != root->val) rootI++;
    // 计算左子树大小
    int lSize = rootI - il;
    // 递归构建左右子树
    root->left = postBuild(
        post, in,
        // 左子树在前半部分
        pl, pl + lSize - 1,
        il, rootI - 1
    );
    root->right = postBuild(
        post, in,
        // 右子树在后半部分
        pl + lSize, pr - 1,
        rootI + 1, ir
    );
    return root;
}
```

## 层序+中序
1. 中序中取在层序中最靠前的节点为根节点
2. 在中序中找到根节点位置，划分左右子树
3. 递归构建左右子树
```cpp
Node* levelBuild(
    int lev[], int in[]， int levn,
    int il, int ir
    ) {
    // 递归出口
    if(il > ir) return nullptr;
    // 在中序中找到层序中最靠前的节点位置
    int rootLevI = levn, rootInI = il;
    // 遍历层序
    for(int i = 0;i < levn;i++){
        // 遍历中序
        for(int j = il;j <= ir;j++){
            // 寻找匹配且位置最靠前的节点
            if(lev[i] == in[j]){
                if(i < rootLevI){
                    // 更新在层序和中序中的位置
                    rootLevI = i;
                    rootInI = j;
                }
                break;
            }
        }
    }
    // 创建新根节点
    Node* root = new Node(in[rootI]);
    // 递归构建左右子树
    root->left = levelBuild(
        lev, in, levn,
        // 左子树在前半部分
        il, rootInI - 1
    );
    root->right = levelBuild(
        lev, in, levn,
        // 右子树在后半部分
        rootInI + 1, ir
    );
    return root;
}
```
