# 二叉树存储
二叉树的存储方式有两种
- 顺序存储
- 链式存储（或数组模拟）

顺序存储适用于完全二叉树
链式存储适用于一般二叉树

### 顺序存储
数组存储二叉树节点
- 根节点存在$a[1]$
- 左子节点在$a[2i]$
- 右子节点在$a[2i+1]$
- 父节点在$a[i/2]$

*空节点可以用特殊值（如-1）表示*
```cpp
void sequentialBT(){
    int a[100]; // 假设二叉树最多有99个节点
    // 初始化数组，-1表示空节点
    for(int i = 0; i < 100; i++) a[i] = -1;
    // 插入节点（以第8号位置为例）
    a[8] = 10; // 根节点
    a[8/2] = 10; // 父节点
    a[8*2] = 5;  // 左子节点
    a[8*2+1] = 15; // 右子节点
}
```
### 链式存储
链表存储，每个节点包含数据和左右指针
*也可以再加入父指针以方便访问父节点*
```cpp
struct BTNode {
    int data;
    BTNode* left;
    BTNode* right;
    BTNode* parent; // 可选
    BTNode(int val, BTNode* p = nullptr, BTNode* l = nullptr, BTNode* r = nullptr)
        : data(val), left(l), right(r), parent(p) {}
};
void linkedBT(){
    BTNode* root = new BTNode(10); // 根节点
    root->parent = root; // 根节点的父节点指向自己或nullptr表示无父节点
    root->left = new BTNode(5, root);// 左子节点
    root->right = new BTNode(15, root);// 右子节点
}
```
### 数组模拟的链式存储
用数组模拟链式存储，每个节点包含数据和左右子节点的索引
```cpp
struct ArrayNode {
    int data;
    int left; 
    int right;
    int parent; // 可选
    ArrayNode(int val = -1, int p = -1, int l = -1, int r = -1)
        : data(val), left(l), right(r), parent(p) {}
};
int idx = 0; // 全局索引，模拟节点分配
// 插入节点函数，返回新节点的索引
int addNode(ArrayNode a[], int val, int parent = -1){
    idx++;
    a[idx] = ArrayNode(val, parent);
    return idx;
}
void arraySimulatedLinkedBT(){
    ArrayNode a[100]; // 假设二叉树最多有99个节点
    // 初始化数组，默认-1表示空节点
    for(int i = 0; i < 100; i++) a[i] = ArrayNode();
    // 插入节点（以第8号位置为例）
    int rootI = addNode(a, 10); // 根节点
    a[rootI].parent = rootI; // 根节点的父节点指向自己或-1表示无父节点
    a[rootI].left = addNode(a, 5, rootI); // 左子节点
    a[rootI].right = addNode(a, 15, rootI); // 右子节点
}
```
