# 二叉树遍历
常见遍历方式有4种
- 前序遍历
- 中序遍历
- 后序遍历
- 层序遍历

前三者都是dfs递归（或栈）实现
最后一种是bfs队列实现

### 二叉树定义
```cpp
struct TreeNode{
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x): val(x), left(nullptr), right(nullptr){}
};
```
### 前序遍历
$ 根节点 \rightarrow 左子树 \rightarrow 右子树 $
```cpp
void preOrder(TreeNode* root){
    // 递归出口
    if(root == nullptr) return;
    // 访问根节点
    cout << root->val << ' ';
    // 访问左子树
    preOrder(root->left);
    // 访问右子树
    preOrder(root->right);
}
```
### 中序遍历
$ 左子树 \rightarrow 根节点 \rightarrow 右子树 $
```cpp
void inOrder(TreeNode* root){
    // 递归出口
    if(root == nullptr) return;
    // 访问左子树
    inOrder(root->left);
    // 访问根节点
    cout << root->val << ' ';
    // 访问右子树
    inOrder(root->right);
}
```
### 后序遍历
$ 左子树 \rightarrow 右子树 \rightarrow 根节点 $
```cpp
void postOrder(TreeNode* root){
    // 递归出口
    if(root == nullptr) return;
    // 访问左子树
    postOrder(root->left);
    // 访问右子树
    postOrder(root->right);
    // 访问根节点
    cout << root->val << ' ';
}
```
### 层序遍历
按层次从上到下、从左到右访问树的节点 
```cpp
void levelOrder(TreeNode* root){
    // 空树直接返回
    if(root == nullptr) return;
    // 队列管理候选节点
    queue<TreeNode*> q;
    // 根节点入队
    q.push(root);
    // 当队列不空时，持续访问节点
    while(!q.empty()){
        // 访问队首节点
        TreeNode* node = q.front();
        cout << node->val << ' ';
        // 出队
        q.pop();
        // 左右子节点入队
        if(node->left) q.push(node->left);
        if(node->right) q.push(node->right);
    }
}
```
