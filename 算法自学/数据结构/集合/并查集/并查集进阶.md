## 带权并查集
### 核心
在普通并查集的基础上增加权值数组，记录每个节点到父节点（或根节点）的权值。
### 作用
处理一些需要维护元素间关系的场景，如距离、差值等。
### 操作
> $a\rightarrow b$: a到b的权值
> $p$: 父节点 parent
> $r$: 根节点 root
> $w$: 权值 weight
#### 初始化
```cpp
// p: 父节点数组，w: 权值数组
vector<int> p(n), w(n);
// 父节点初始化为自己，权值初始化为0
for(int i = 0; i < n; i++) p[i] = i, w[i] = 0; 
```
----
#### Find
- 更新逻辑
> 1. 新父节点 = 根节点 $r$
> $\therefore$更新$w_x$为 $x\rightarrow r$ 权值
> 2. 原$w_x$为 $x\rightarrow p$ 权值
> 3. 递归栈结构，保证$w_{p_x}$已更新为$ p \rightarrow r$ 权值
> 4. 权值 $x\rightarrow r = x\rightarrow p\rightarrow r$
> $\therefore$ $w_x = w_x + w_{p_x}$
- 更新顺序
> 1. 先更新权值，此时父节点还是原来的父节点
> 2. 后路径压缩，父节点更新为根节点
```cpp
int find(int x){
    if(p[x] != x){
        // 找到根节点
        int t = find(p[x]);
        // 先更新权值（保证父节点有效）
        d[x] += d[p[x]]; 
        // 后路径压缩
        p[x] = t; 
    }
    return p[x];
}
```
----
#### Union
更新逻辑
> $w_0$ 为 $y\rightarrow x$ 权值
> $r_*$ 为 $*$ 的原根节点
> 1. $y\rightarrow r_y = y\rightarrow x\rightarrow r_x$
> 2. $y\rightarrow r_y = y\rightarrow x\rightarrow r_x$
> $\therefore w_y + w_{ry} = w_x + w_0$
> $\therefore w_{ry} = w_x - w_y + w_0$
```cpp
// w0为y到x的权值
bool unite(int x, int y, int w0){
    // 找到根节点
    int rx = find(x);
    int ry = find(y);
    // 已在同一集合，检查权值合法
    if(rx == ry) return w[y] - w[x] == w0;
    // 不在同一集合，先合并集合
    // 这里也可以加入优化，如按秩合并
    p[ry] = rx;
    // 更新权值
    d[ry] = d[x] - d[y] + w0;
    return true;
}
```

## 离线并查集
### 核心
- 先记录所有操作
- 将分离转换为逆向合并
- 或重排序规避分离操作
### 作用
处理需要动态修改关系、分离集合的场景，如动态连通性、动态图等。
