# 并查集
[TOC]
## 定义
并查集（Union-Find）用于处理一些**不交**集的合并及查询问题。它支持两种操作：
1. **合并（Union）**：将两个元素所在的集合合并成一个集合。
2. **查询（Find）**：查询一个元素所在的集合。

## 存储
通常用一个数组存每个元素的父节点。
- 初始时每个元素的父节点是它自己。
- 根节点的父节点是它自己。
```cpp
vector<int> p(n);
```

## 操作
### 初始化
将每个元素的父节点设为自己。
```cpp
vector<int> p(n);
for(int i = 0; i < n; i++) p[i] = i;
```
----
### Find
查询一个元素所在的集合，返回根节点。
#### 实现方式
如果父节点不是自己，递归查找父节点。
#### 代码
```cpp
int find(int x){
    // 父节点不是自己，不是根节点，继续向上查找
    if(p[x] != x) return find(p[x]);
    // 返回根节点
    return p[x];
}
```
----
### Union
将两个元素所在的集合合并成一个集合
#### 实现方式
找两个元素的根节点，如果不同，连接这两个根节点。
#### 代码
```cpp
void unite(int x, int y){
    // 找到两个元素的根节点
    int rtX = find(x);
    int rtY = find(y);
    // 将rtX的父节点设为rtY（反过来也行）
    if(rtX != rtY) p[rtX] = rtY;
}
```

## 优化
### 路径压缩
在Find操作中，将访问过的节点直接连接到根节点。
#### 意义
将树的高度压缩到几乎为1
#### 代码
```cpp
int find(int x){
    // 递归父节点，找到根节点后连接
    if(p[x] != x) p[x] = find(p[x]);
    // 一定是根节点
    return p[x];
}
```  
----
### 按高度（秩）合并
在Union操作中，将高度较小的树连接到高度较大的树。
>注：与路径压缩搭配时，高度持续改变，判断基于估计高度而不是实际高度。
#### 意义
每次合并都使高度尽量小，高度不会超过$\log n$
- 高度不同：合并后高度不变
- 高度相同：合并后高度加1
#### 代码
```cpp
// 单开高度数组（也可用结构体），初始高度1
vector<int> h(n, 1);
void unite(int x, int y){
    int rtX = find(x);
    int rtY = find(y);
    if(rtX != rtY){
        // 将高度较小的树连接到高度较大的树
        if(h[rtX] < h[rtY]) p[rtX] = rtY;
        else if(h[rtX] > h[rtY]) p[rtY] = rtX;
        // 高度相同随便连，连接后高度加1
        else p[rtX] = rtY, h[rtY]++;
    }
}
```
----
### 按大小合并
在Union操作中，将元素较少的树连接到元素较多的树。
#### 意义
- 同样能使树的高度保持较小，不超过$\log n$
- 顺便得到每个集合的大小
#### 代码
```cpp
// 单开大小数组，初始大小1
vector<int> sz(n, 1);
void unite(int x, int y){
    int rtX = find(x);
    int rtY = find(y);
    if(rtX != rtY){
        // 将元素较少的树连接到元素较多的树，并更新大小
        // 先更新再连接，应对负数p表示大小的情况
        if(sz[rtX] < sz[rtY]) sz[rtY] += sz[rtX], p[rtX] = rtY;
        else sz[rtX] += sz[rtY], p[rtY] = rtX;
        // 大小相同随便连，更新大小也一样
    }
}
```
>注：可以把根节点的p设为负数，绝对值表示h或sz，不需单开数组。
## 复杂度
### 朴素并查集
- 平均$O(\log n)$，最坏情况为链状树$O(n)$
### 优化后并查集
- 近似$O(1)$，实际为$O(α(n))$
> $α(n)$为反阿克曼函数，一般数据范围内$α(n)\leq 4$，因此可以认为是常数。
