# 策略计划

> 主动规划学习方向，不被动等总结 📋

## 文件夹用途

| 文件 | 说明 |
|:---|---|
| `弱项突破.md` | 针对薄弱领域（DP、字符串、计算几何等）的定点刷题计划 |
| `赛前准备.md` | 洛谷比赛前提醒热身，赛后复盘记录 |
| `间隔复习.md` | 旧知识点的间隔复习计划，防遗忘 |
| `错题本.md` | 跟踪翻车题目，标记回刷状态 |

## 规则

- **弱项突破**：每周日总结后，由 Cherry 自动评估薄弱环节并更新题单
- **赛前准备**：检测到洛谷新比赛时，自动生成赛前提醒
- **间隔复习**：结合遗忘曲线，定期推送需要复习的知识点
- **错题本**：追踪 AC 率低于平均的题目，标记 "已回刷" / "待回刷"
