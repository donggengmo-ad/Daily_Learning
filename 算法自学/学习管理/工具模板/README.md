# 工具模板

> 磨刀不误砍柴工，减少重复劳动 🛠️

## 文件夹用途

| 文件 | 说明 |
|:---|---|
| `笔记骨架.md` | 新算法笔记的标准模板（定义→分类→实现→复杂度→代码） |
| `Anki卡片/` | 从笔记提取关键知识点生成的 Anki 导入卡片 |
| `代码模板/` | 竞赛常用算法的标准代码片段（树状数组、线段树、KMP……） |

## 规则

- **笔记骨架**：学新算法前由 Cherry 自动生成，填入即可
- **Anki 卡片**：每周总结时同步提取，生成可导入 Anki 的文本
- **代码模板**：笔记中出现的算法自动提取标准实现
